# 客户端资源容量

[English](client-resource-capacity.md)

关闭对应游戏后，在 Mod Manager 选择 DIY 客户端，点 **客户端 LAA**。Manager 会核对已登记 32 位游戏程序的完整原版摘要，再切换 PE 标志。再次操作可以恢复原版字节。服主管理的客户端由服主提供的运行包决定。

在 64 位 Windows 上，LAA 允许 32 位游戏使用最多 4 GiB 虚拟地址空间。地图编译与导入由 64 位 Manager 处理。在 **地图与任务导入** 编译发布包，或用 **从磁盘安装地图 ZIP** 导入已有发布包。Manager 从磁盘分块校验和暂存资源，在所选客户端关闭期间完成安装。大包最多可含 32 段原生归档，归档总量最多 2 GiB。安装后重启客户端，新地图也需要应用配套服务端计划。

游戏运行时按需从归档打开各个资源。游戏对单项资源、模型格式和图形设备的限制仍适用。
