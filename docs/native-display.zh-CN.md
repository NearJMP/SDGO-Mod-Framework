# 原生无边框显示

[English](native-display.md) · [功能索引](../README.zh-CN.md)

在 SDGO Mod Manager 启用「原生无边框显示」，选择分辨率后重启游戏。战斗中「桌面分辨率」按实际渲染尺寸铺满启动所在的显示器。选择较小的固定档时，无边框窗口按实际像素大小居中。固定档大于显示器时，支持范围内会采用桌面分辨率。

战斗按所选像素尺寸渲染，HUD 沿用游戏的宽屏坐标。登录和大厅的 1024×768 原生画布会等比放大，显示在居中的 4:3 窗口。鼠标位置会换算回画布坐标。机体、贴图、界面美术和文字继续使用客户端素材。提高战斗分辨率会增加显存和渲染开销。

在 Manager 停用后重启，即可使用游戏的原有显示选项。
