# 原生无边框显示

[English](native-display.md) · [功能索引](../README.zh-CN.md)

在 SDGO Mod Manager 启用「原生无边框显示」，选择分辨率后重启游戏。战斗中「桌面分辨率」按实际像素尺寸铺满启动所在的显示器。选择较小的固定档时，无边框窗口按实际像素大小居中。固定档大于显示器时，仍按所选尺寸渲染，再等比适配窗口。例如在 1440p 屏上选择 2160p，战斗会先渲染出 3840×2160 画面。

「战斗 HUD 大小」可以单独调整。自动档在 2160p 将战斗状态栏、小地图、武器栏、瞄准标记和相应文字放大到 150%，1440p 及以下沿用原有大小。也可以选固定的 125% 或 150%，或者关闭 HUD 放大。登录和大厅沿用居中的 4:3 画布，鼠标位置映射到当前画布。提高战斗分辨率会增加显存和渲染开销。

在 Manager 停用后重启，即可使用游戏的原有显示选项。

## 本地图片高清预览

在「游戏功能 → 原生无边框显示 → 设置」展开「本地图片高清预览」。选择原图 PNG 和倍率，点「生成本地预览」。每张图的宽高分别放大为 2 倍或 3 倍。可以保存 PNG，或者点「在游戏中使用」并重启已启用本 Mod 的客户端。更换同一原图的倍率会覆盖这条本地设置。用「恢复原图」移除本地设置，重启后即可还原。

游戏按完整原图的像素匹配兼容的静态界面图集。请使用与所用客户端对应的完整原图 PNG，保留原图的透明边和格子位置。同一个图集可能含多个按钮和图标，游戏会把原有裁剪框等比例换算到新图，使用原生布局和命中区域。找不到原图或无法读取增强图时，游戏会继续显示自己的原图。机体模型、场景、动画和战斗特效通过提高实时渲染分辨率改善显示。

也可以在本机用 [Real-ESRGAN](https://github.com/xinntao/Real-ESRGAN) 等工具处理背景、插画和纹理。把 AI 成图选入「自备 AI 输出 PNG」，并排比较常规版和 AI 版。Manager 会校验尺寸、恢复原图透明度。给你已有的本地 AI 使用以下指示，把 `N` 换成选中的倍率：

> 等比放大到原图宽和高各乘 N，输出 sRGB PNG。保留机体配色、构图、轮廓、图标、文字和边框。只增强已有细节，弱化锐化。保留完整颜色，导出到单独的文件。

预览和应用都在本地完成。本地图片可以独立管理，原图和成图由玩家自行准备。
