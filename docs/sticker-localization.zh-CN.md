# 原版贴纸名称中文汉化

[English](sticker-localization.md) · [返回功能目录](../README.zh-CN.md)

`sticker_localization` 将当前原版贴纸基线中已经审定的名称显示为简体中文，只改变显示文字。
贴纸图片、材质、尺寸、库存、价格及玩家作者内容继续使用原有流程。

## 使用

玩家通过服主提供的客户端包或更新取得本 Mod。在 SDGO Mod Manager 中启用
「汉化原版贴纸名称」后重启客户端。该开关独立存在并默认开启；关闭后重启，
贴纸名称与分类名称保留原文。

本 Mod 依赖 `ui_localization`，因为后者已经拥有已核实的原生 GridData 查询挂钩。
`sticker_localization` 只提供只读文字查询，不会在同一位置安装第二个挂钩。
`sticker_catalog` 是可选依赖；已加载目录声明拥有某条贴纸时，或归属结果缺失、异常、
格式不合法时，原版汉化都会保留作者写入的完整原名。

[商城中文汉化](shop-localization.zh-CN.md)会把当前全部原版贴纸分类交给本提供器。
每条分类保留自己已经审定的中文结果；分类译名不会被推断成关联贴纸的原生名称。
自定义商品标题仍保持最高优先级。本提供器关闭、缺失或拒绝精确匹配时，商城保留分类原文，
不再套用普通商城词典。

## 覆盖与匹配

当前基线共有 414 条原版贴纸记录：286 条为已审定的含英文字母 ASCII 名称，
127 条为非 ASCII 名称，另有一条不完整的 ASCII 原文 `" Sticker"`。原生名称词表共有
298 组贴纸编号与完整原文精确键：完整收录 286 条已审定 ASCII 英文记录，并收录
12 条具有唯一明确中文名称的非 ASCII 记录。其他原生贴纸名称，包括存在歧义的专名音译
和不完整原文，均保持原样。

独立商城词表收录当前第 17 类的全部 347 条分类记录。每条都以分类编号和完整分类原文为键，
同时记录有类型的贴纸关联、精确基线贴纸原文及该分类自己原有的审定中文结果。商城查询先核对
精确分类键，再核对精确关联贴纸的内容归属，最后返回分类自身保存的中文结果；不会按编号、
原文或全局词典单独回退。

原生名称例子：

| 贴纸编号 | 完整原文 | 显示结果 |
| ---: | --- | --- |
| `240005` | `Triangle Sticker` | `三角形贴纸` |
| `240358` | `삼국전 여포군 스티커` | `三国传吕布军贴纸` |
| `240009` | `즐 Sticker` | 保留原文 |
| `240335` | ` Sticker` | 保留原文 |
| `240005` | `Triangle Sticker?` | 保留原文 |

精确商城分类例子：

```text
shop(category_id=1710005, source="즐 스티커",
     sticker_id=240009, sticker_source="즐 Sticker") -> "“兹尔”贴纸（音译）"
sticker(sticker_id=240009, source="즐 Sticker") -> no match

shop(category_id=1720156, source="龍 Sticker",
     sticker_id=240335, sticker_source=" Sticker") -> "龍贴纸"
sticker(sticker_id=240335, source=" Sticker") -> no match

shop(category_id=1720156, source="龍 Sticker?") -> no match
shop(category_id=1720156, source="龍 Sticker", ownership=owned) -> no match
shop(category_id=1720156, source="龍 Sticker", ownership=unknown) -> no match
```

分类已经审定的显示名称不会授权汉化其关联的原生贴纸名称；两个命名空间分别保留自己的精确键和目标。
两类查询在内容归属为 `owned` 或 `unknown` 时都会拒绝，从而保护复用原版编号或文字的自定义名称。

## 实现与验证边界

提供器导出有固定边界的进程内查询。现有 `ui_localization` 分发器复制完整的 409 字节
原生贴纸记录，只替换第 `5` 至 `104` 字节的 50 个宽字符名称槽，并返回稳定缓存副本；
原记录及其他所有字节保持不变。商城显示在有类型的贴纸归属保护通过后，直接返回精确分类投影中
保存的目标文字。

生成词表、格式拒绝、精确词典查询、提供器缓冲区语义、内容归属保护、分类别名、记录复制边界及
原有系统提示路径均有聚焦的离线测试。这些检查证明实现契约；受支持客户端中的实际画面与玩法验收
会在完成演示后另行记录。
