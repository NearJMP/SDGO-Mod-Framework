# SDGO Mod Manager 1.16.46

## 中文

- 好友列表服务端修复更新至 0.1.5，兼容 `nvarchar(20)` 至 `nvarchar(4000)` 的角色名列，包括 `nvarchar(50)`，避免列宽检查导致登录后好友列表读取失败。
- 保留原有列排序规则、名字编码和协议长度限制；较短列、其他类型和 `nvarchar(max)` 继续拒绝。安装后重启 WorldServer，并重新登录客户端读取好友列表。
- 开发者可使用原生 OLE DB 元数据检查，验证列布局并生成查询，而不安装查询或修改持久表。

## English

- Update the friend-list server repair to 0.1.5. Pilot-name columns from `nvarchar(20)` through `nvarchar(4000)`, including `nvarchar(50)`, pass the layout check so wider columns no longer prevent friend-list retrieval after login.
- Preserve the existing column collation, native name encoding and protocol length limits. Shorter columns, other types and `nvarchar(max)` remain rejected. Restart WorldServer after installation and log in again to reload the list.
- Developers can validate column layouts and generate queries with the native OLE DB metadata check without installing queries or modifying persistent tables.
