# SDGO Mod Manager 1.16.48

## 中文

- 好友机体赠送客户端 0.1.12：功能探测没有回复或发送暂时失败时，在同一次登录内按 5、15、60 秒退避重试。迟到的旧扩展回包不会拒绝新的短请求；明确的协议拒绝与服主关闭赠送的策略继续有效。自动重试只用于只读功能探测，赠送、接受、退还及结果未确认状态保持原有确认规则。
- 保管库一键领取 0.2.1：批次中每次继续前都检查原生请求是否空闲，等待到账、物品与礼物列表等后续请求完成。暂停后继续无需再次确认，等待期间仍可停止批次。
- 原生数据与生命周期修复 0.3.5：访问异常记录已加载主程序的指令字节，包括实际挂钩。已验证的模型节点分发故障另保留有限的节点指针窗口；不可读或不匹配的布局停止诊断读取，保留原始异常处理和上下文。
- 保留 1.16.47 的贴纸导入、纹章汉化和机体外观改进，包括任务过场中无备用变形模型的分支修复。

更新通过服主提供的客户端包或更新安装，重启客户端后生效。未确认的赠送结果仍应查询原请求回执。

## English

- Friend unit gifts client 0.1.12 recovers discovery in the same login after a missing reply or failed send, using 5, 15 and 60 second backoff. Delayed expanded replies cannot reject a fresh short probe. Explicit protocol refusals and disabled gifting policy remain authoritative. Only read-only discovery retries automatically; offers, acceptance, returns and uncertain outcomes retain their existing confirmation rules.
- Storage claim all 0.2.1 checks native pending requests before each continuation. Grant, item-list and gift-list follow-ups finish before the batch continues, without another confirmation. Stop remains available while waiting.
- Native data and lifecycle guards 0.3.5 retain live host instruction bytes on access violations, including installed hooks. The verified model-node dispatch fault also records a bounded node-pointer window. Unreadable or unmatched layouts stop the diagnostic read while preserving original exception handling and context.
- Retains the sticker import, localization and appearance improvements from 1.16.47, including the cutscene branch fix for units without an alternate model.

Install the server owner's client package or update and restart the client. Resolve uncertain gift outcomes through the original request receipt.
