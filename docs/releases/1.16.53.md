# SDGO Mod Manager 1.16.53

## 中文

- 修复弱网下机库分页加载期间切换“我的房间”导致的“客户端环境异常”。已经开始分页时，客户端先完成当前库存读取，再执行刚才的切换。首次进入机库仍会正常开始加载。

## English

- Fixes the abnormal client environment warning when switching to My Room while inventory pages are still arriving over a slow connection. The client finishes the active inventory load, then opens My Room. The first visit can still start an inventory load.
