# SDGO Mod Manager 1.16.53

## 中文

- 修复弱网下切换页面打断机库分页，并触发“客户端环境异常”。底栏统一等当前库存分页收齐，再打开“我的房间”、活动扭蛋或商城等目标页面。首次进入机库仍会正常开始加载。

## English

- Fixes the abnormal client environment warning caused by interrupting inventory pagination during navigation on a slow connection. The bottom navigation waits for the current load to finish before opening My Room, capsules, the shop or another destination. The first visit can still start an inventory load.
