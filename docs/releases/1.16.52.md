# SDGO Mod Manager 1.16.52

## 中文

- 导入地图的选图图标改为原版样式：房间界面里的地图图片上方显示发光像素字的英文地图名牌，下方是场景画面，与原版地图一致。名牌由编译器自动生成，字形取自客户端自带的地图预览图集，图集里没有的字符用同风格的内置像素字体；地图作者只需提供场景图。
- 修复导入地图在边缘附近整片变成半透明：原版小物件挡住镜头时会淡化，但导入地图常把整座场馆或整片草地做成一个模型，导致一挡镜头整张图都变透明。现在可行走地面和宽度超过 30 米的模型默认保持不透明，地图包 v3 也可以用 `objects[].camera_fade` 逐个指定。

在 Manager 中重新编译地图并安装客户端包后生效。

## English

- Imported maps now show the shipped room-screen icon: the English map name as a glowing pixel tag above the scene picture, like the shipped maps. The compiler generates the tag with glyphs from the client's own map preview atlas and a built-in pixel font of the same style for characters the atlas lacks; authors supply only the scene picture.
- Fixes imported maps turning see-through near their edges. Shipped props fade while they block the camera, but imported maps often make a whole stadium or field of grass a single model, so the entire map faded. Walkable ground and models wider than 30 m now stay opaque by default, and map package v3 can set `objects[].camera_fade` per object.

Recompile the maps in Manager and install the client package.
