# SDGO Mod Manager 1.16.58

## 中文

- 新增可选的原生无边框显示 Mod。战斗可选桌面分辨率、1080p、1440p 或 2160p。菜单沿用原有界面和素材，按原画布等比放大并换算鼠标坐标。

## English

- Adds an optional native borderless display mod. Battle renders at Desktop, 1080p, 1440p or 2160p. The original menu canvas scales proportionally and maps pointer input back to its controls.
