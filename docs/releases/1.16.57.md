# SDGO Mod Manager 1.16.57

## 中文

- 修复登录后库存同步期间切到「我的房间」或换频道时，原生客户端重复请求库存分页并提示“因非正常游戏环境，客户端即将关闭”的问题。底栏和顶部频道按钮等当前库存同步完成后自动继续。

## English

- Fixes duplicate inventory page requests that could trigger the abnormal game environment shutdown warning when opening My Room or switching channels during login. Bottom navigation and the top channel buttons continue automatically once the current inventory sync finishes.
