# SDGO Mod Manager 1.16.50

## 中文

- 地图包 v3 新增模型地面 `objects[].ground`：选中模型中应该站上去的表面（glTF 节点名称，或 `true` 表示整个模型），编译器在其覆盖的地形格点取模型上表面的高度。机体的行走高度与看到的地板一致，不再穿到地板下面或悬在半空。
- 新增 `terrain.render: false`，隐藏高度图地形表面，只显示模型作为地面，与大多数原版地图的做法相同，避免地形与模型地板重叠闪烁。
- 出生点、道具点和传送台按生成后的地面检查；节点名称不存在或所选网格没有覆盖地形时编译报错。物件字段用错地图包版本时，直接提示所需的 `schema_version`。
- 文档写明高度图和遮罩的第 0 行是北边（+Z）。

在 Manager 中重新编译地图并安装客户端包后生效。v1 和 v2 地图包照常读取。

## English

- Map package v3 adds model ground, `objects[].ground`: select the model surfaces people should stand on (glTF node names, or `true` for the whole model) and the compiler takes their top surface height at every terrain grid vertex they cover. Units walk at the height of the floor they see instead of sinking under it or hovering above it.
- `terrain.render: false` hides the height-map terrain surface so the models are the only visible ground, as in most shipped maps, and the terrain no longer flickers through a model floor.
- Spawns, item points and launch pads are checked against the resulting ground. Unknown node names, or a selection that covers no terrain, are compile errors. Object fields used with too old a package version now name the required `schema_version`.
- The guide states that row 0 of height and mask images is the north edge (+Z).

Recompile the maps in Manager and install the client package. v1 and v2 map packages remain readable.
