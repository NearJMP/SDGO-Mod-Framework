# SDGO Mod Manager 1.16.56

## 中文

- 新增游戏运行时的 64 位资源后台。带运行时声明的地图包由独立进程按需解压和缓存，游戏通过原生资源入口读取。
- 新版原生归档总量超过 128 MiB 的地图包自动声明依赖。Manager 在编译和安装时提醒作者，并检查资源后台与已启用的配套资源目录 Mod。

## English

- Adds a 64-bit live resource worker. It decompresses and caches marked map resources on demand while the game reads them through its native resource broker.
- New map packages with more than 128 MiB of native archives declare the dependency automatically. Manager shows the requirement and checks the worker and any active shared resource brokers.
