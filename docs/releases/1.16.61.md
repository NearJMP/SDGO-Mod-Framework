# SDGO Mod Manager 1.16.61

## 中文

- OC 客户端 0.6.21 与 World 服务端 0.5.3：强化道具列表显示真实库存与读取状态，兼容保留的 100% 成功卡和等级保护卡；进入页面时平滑滑入且首帧不闪现。阻止隐藏库存拖出无关道具，挑战按钮各状态文字保持居中，Ex 按钮可正常打开技能选择；服务端重启后的首次能力查询正确报告 EX 支持。
- 机体外观客户端 0.2.8 修复贴花原图及磨损纹理在退出清理时阻塞，导致游戏窗口关闭后进程残留的问题。

- 原生无边框显示新增独立的战斗 HUD 设置。2160p 自动档将战斗状态信息放大到 150%。
- 可从本地高清预览把匹配的 PNG 应用到游戏界面，并在 Manager 恢复原图。程序包提供工具和说明，图片由玩家自己准备。

## English

- OC client 0.6.21 and World server 0.5.3: show actual enhancement inventory and loading states, including retained 100% success and level-protection coupons. Panels slide in without a first-frame flash. Hidden inventory cannot start unrelated item drags, challenge captions stay centered across button states, and Ex opens the ability selector. The first capability query after a World restart reports EX support correctly.
- Unit appearance client 0.2.8 fixes sticker and wear-texture teardown blocking game exit and leaving the process running after its window closes.

- Native borderless display adds independent battle HUD sizing. Auto enlarges the battle status overlays to 150% at 2160p.
- Use a matching PNG from the local preview in game and restore the original from Manager. The release supplies the tools and instructions. Players supply their own artwork.
