# SDGO Mod Manager 1.16.47

## 中文

- 新增独立的自定义贴纸导入工具：在 Manager 中保存项目、导入常见图片、检查透明背景和比例、设置首次放置尺寸，并生成配套的客户端纹章与物品类别、服务器定义。内置“大肥鱼”公开示例，获取规则由服主决定。
- 支持 PNG、JPEG、BMP、GIF、WebP、TIFF、TGA、DDS、ICO、AVIF、HEIC/HEIF 和受限的自包含 SVG。客户端内容使用摘要清单分发，安装保留其他项目，并可恢复中断的事务。
- 新增独立的原版贴纸名称汉化开关，按原版编号与完整原文匹配，保留自定义名称及既有的精确商城别名。
- 机体外观客户端更新至 0.2.7，读取导入贴纸的首次放置尺寸，并将任务过场 RGB 观察点移至完整分支汇合入口，避免无备用模型分支跳入被覆盖指令的中间。

## English

- Add a standalone custom sticker importer in Manager: save projects, import common images, review transparency and proportions, set first-placement dimensions, and generate paired client emblems/item categories and server definitions. A public **大肥鱼** example is included; owners control acquisition.
- Support PNG, JPEG, BMP, GIF, WebP, TIFF, TGA, DDS, ICO, AVIF, HEIC/HEIF and a restricted self-contained SVG subset. Content uses hash manifests; installation preserves other projects and recovers interrupted transactions.
- Add an independent stock-sticker localization switch using exact baseline IDs and full source text, preserving authored names and existing exact shop aliases.
- Update the appearance client to 0.2.7 with imported first-placement dimensions and a cinematic RGB observation site at the complete branch join, avoiding an incoming null-model branch landing inside overwritten instructions.
