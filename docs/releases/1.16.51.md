# SDGO Mod Manager 1.16.51

## 中文

- 修复高密度地图模型导致进图崩溃：客户端每个模型节点最多接受 65535 个索引（21845 个三角面），超过时不会创建索引缓冲，随后的上传会访问空指针。地图编译器原来只按 65535 个顶点拆分节点，现在同时按三角面数拆分，并在校验中报告超限的节点。
- 地图模型因此可以使用接近一百万个顶点和一百万个三角面（例如成片的草丛），编译器会自动拆成客户端能加载的节点。原有地图不受影响：没有超过上限的节点保持原样。

在 Manager 中重新编译地图并安装客户端包后生效。

## English

- Fixes a crash when entering a map with a dense model. The client accepts at most 65535 indices (21845 triangles) per model node; a larger node gets no index buffer and the upload that follows dereferences a null pointer. The map compiler used to split nodes only at 65535 vertices; it now also splits by triangle count, and validation reports nodes over the limit.
- Map models can therefore use close to one million vertices and one million triangles (for example fields of grass), split automatically into nodes the client can load. Existing maps are unaffected: nodes within the limits stay as they were.

Recompile the maps in Manager and install the client package.
