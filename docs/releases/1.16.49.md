# SDGO Mod Manager 1.16.49

## 中文

- 地图与任务导入新增传送台：地图包 v3 的 `launch_pads` 声明入口中心与落点，机体碰到后沿直线飞到落点再照常落地。编译器换算为游戏原生的强制移动区域，本机立即起飞并经 Battle 服务端转发给房间内其他玩家；房主控制的对战 AI 也会按同样流程使用。传送台不需要服务端数据。
- 编译时检查传送台的距离、落点高度和活动范围，并拒绝穿过地形或带碰撞物件的飞行路线，报错给出传送台编号。v1 和 v2 地图包照常读取。
- 原生测试新增传送台飞行检查，核对本机飞行终点与原生运动规律一致，以及 AI 的传送请求获得服务端转发。

在 Manager 中重新编译地图并安装客户端包后生效；只增加传送台时无需改动服务端数据。

## English

- Map and mission import adds launch pads. Map package v3 `launch_pads` declare an entry centre and a landing point; a unit that touches the pad flies straight to the landing point and lands normally. The compiler produces the game's own forced-move volumes: the local client launches immediately and the Battle server relays the move to everyone else in the room. Host-controlled PvP AI use the same flow. Launch pads need no server data.
- Compilation checks pad distance, landing height and play area, and refuses flights through terrain or colliding objects, naming the pad. v1 and v2 map packages remain readable.
- Native tests add a launch-pad flight check: the local flight must end where the native motion model predicts, and AI pad requests must be relayed by the server.

Recompile the maps in Manager and install the client package. Adding launch pads alone does not change server data.
