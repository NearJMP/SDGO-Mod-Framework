# SDGO Mod Manager 1.16.54

## 中文

- DIY 客户端可以在 Mod Manager 启用或关闭 LAA。Manager 核对完整原版程序摘要，切换后在下次启动生效。
- 地图与任务导入支持从磁盘校验和安装多段归档。64 位 Manager 处理发布包，游戏按需从原生归档读取单项资源。

## English

- DIY clients can enable or disable LAA from Mod Manager. Manager verifies the complete original executable digest, and the change takes effect at the next game start.
- Map and mission import can verify and install segmented archives from disk. The 64-bit Manager handles the publication, and the game opens individual resources from its native archive format.
